# 主表字段与解析约定

下列为本轮实现采用的字段解释，供周静雯核对和整理材料。数据为原发布者历史快照；不是2026年实时市场。

| 原始列 | 含义与本轮用法 |
| --- | --- |
| App | 应用展示名称；不是经过验证的唯一ID，不据此合并记录。 |
| Category | 商店分类；用于解释及智能体可选分类插补，不作为聚类标签。 |
| Rating | 评分；本轮按任务文档采用0到5范围；缺失只表示未记录。进入聚类。 |
| Reviews | 评论数量，按非负整数字符串解析。进入聚类。 |
| Size | 应用大小，M按MB、k按0.001MB；随设备变化保留varies状态。数值代理进入聚类。 |
| Installs | 带+的安装量档位下界；去逗号和+后作数值，不能当精确安装量。进入聚类。 |
| Type | Free/Paid等付费类型；报告缺失和与Price冲突，不进入聚类。 |
| Price | 价格，按美元数值解析，Free通常对应0；进入聚类。 |
| Content Rating | 内容年龄分级，保留原值，报告缺失，不进入聚类。 |
| Genres | 类型/流派文本，保留原值，不进入聚类。 |
| Last Updated | 最后更新时间；按英文月份日期解析为ISO日期，不进入聚类。 |
| Current Ver | 当前版本文本，保留原值及缺失，不进入聚类。 |
| Android Ver | 所需Android版本文本，保留原值及缺失，不进入聚类。 |

`source_row_id`是数据记录序号，从1开始。已知错位记录为10473；若计入一行表头，常见CSV显示行号为10474，但程序不将此当物理行号约定。

所有原始列原样保留。`rating_observed`和`size_mb_observed`只存可解析观测；`rating_value`和`size_mb`是可能经填补的建模值，配套`rating_imputed/size_imputed`标记。`eligible_for_clustering`与`cluster_exclusion_reason`区分清洗保留和参与聚类。其他原始列仍可能缺失，并不因为没有进入聚类而在质量报告中隐去。
