
# 数据质量分析与预处理智能体

《数据仓库与数据挖掘》课程小组项目。

> 当前阶段：项目初始化与数据准备。选题、数据集和技术架构待确定；下文描述的是计划目标，不代表功能已经实现。

## 1. 项目目标

设计并实现一个能够自主完成数据质量分析与预处理的数据处理智能体，并支持一个分类或聚类任务。

重点处理四类数据质量问题：缺失值、重复数据、异常值或噪声、数据类型或格式不一致。

智能体需要根据检查结果选择处理方法、调用工具完成处理，并保留处理理由、工具调用及错误修正记录，而不只是执行一套固定的清洗规则。

## 3. 计划工作流与实验

计划工作流：

读取数据 → 分析数据质量 → 制定处理方案 → 调用工具处理 → 检查处理结果 → 分类或聚类 → 输出结果与运行记录。

按照组内实验安排，比较以下三种方案：

- 最低必要处理。
- 固定规则处理。
- 智能体处理。

使用一致的数据划分和下游任务方法；如选择聚类，提前确定比较标准。比较数据质量改善、任务效果、耗时与费用，如实记录未改善或效果下降的情况。

保存模型名称、提示词、参数、调用次数、成本，以及工具调用、错误和修正过程。提交前检查并移除密钥和敏感信息。
